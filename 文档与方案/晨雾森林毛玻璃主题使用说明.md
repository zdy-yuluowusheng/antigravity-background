# 晨雾森林毛玻璃主题使用说明

本文档记录了为 **Antigravity 2.0 桌面端** 定制的壁纸毛玻璃主题配置详情。

* **适用平台**：Google Antigravity 2.0 (由 BetterGravity 驱动)
* **底图文件**：`C:\Users\ylws\Pictures\wallhaven-3zgdd3_2560x1440.png`

## 二、核心设计与效果特性

1. **全局丁达尔光影背景 + 柔和暗化遮罩**：
   - 提取壁纸中央的松林晨雾丁达尔光线；
   - 叠加 `32%` 深墨绿抗疲劳暗化渐变层，彻底消除纯白背景过曝刺眼的问题，同时保证前景色文字的高对比度。
2. **通透磨砂亚克力侧边栏**：
   - 背景透明度 `0.58` + `16px` 高斯模糊 + `150%` 饱和度增强；
   - 透出左侧斜射的晨光微光。
3. **主对话区（Chat Canvas）**：
   - 背景透明度 `0.68` + `12px` 磨砂毛玻璃，文字沉浸感强。
4. **消息卡片与输入框微光**：
   - 消息气泡背景透明度 `0.62`，配合微弱投影；
   - 底部输入框加入晨曦绿（`rgba(52, 211, 153, 0.28)`）微光外边框。
5. **视口锁定与自适应**：
   - `background-attachment: fixed` 确保上下滚动长对话时，底图壁纸稳固居中不抖动、不跟随滚动。

## 四、后续个性化微调

如果你想进一步调整透明度或模糊度，可以直接打开 `晨雾森林毛玻璃主题.css` 调整数值：
* **更透一点**：将各区域的 `rgba(..., 0.68)` 中的 `0.68` 改小（如 `0.5`）；
* **更深一点**：改大数值（如 `0.8`）；
* **更模糊 / 更清晰**：调整 `blur(12px)` 中的数值。
保存后，在 Antigravity 2.0 中按 <kbd>Ctrl</kbd> + <kbd>R</kbd> 即可即时看到最新效果。
