# 新对话窗口下拉选择菜单（项目、模型、工作区）毛玻璃雾化与抗放大方案

本文档记录了在 Antigravity 2.0 桌面端新对话窗口中，针对 **项目目录下拉框**、**模型选择下拉框** 与 **工作区选择下拉框**（Local / New Worktree）展开时呈现纯透明、文字穿透重叠，以及鼠标悬停时出现突兀黑底色块问题的成因剖析、技术方案设计，并重点记录了彻底解决点击展开时“背景出现放大动作”的深层根因分析与底图渲染架构重构落地。

---

## 一、问题背景与现象

在应用晨雾森林毛玻璃主题后，用户在新建对话窗口操作时反馈：
> 1. “新对话窗口中，项目目录、模型、工作区的下拉选择都做成雾化处理效果吧，现在是纯透明的鼠标移动上去后会显示一个黑色的底。”
> 2. “不太对，现在相当于背景是纯黑的 ，我想要的是和对话框一样的透明雾化效果。而且现在点击下拉的时候背景会有一个放大的动作，感觉不太合理。请你重新调整。”
> 3. “样式没有问题，但是现在点击项目目录、模型选择还是会存在背景放大的问题，工作区选择目前是正常的没有放大效果。”
> 4. “背景还是会出现放大动作，很奇怪”

---

## 二、缺陷成因深度剖析

### 1. 全局卡片与背景穿透规则导致的纯透明
为了让 Antigravity 整体界面直显 4K 晨雾森林高清壁纸，主题第 1 节将基础 CSS 变量进行了全局穿透处理：
```css
:root {
    --background: 0 0% 0% / 0 !important;
    --card: 0 0% 0% / 0 !important;
    --card-border: 0 0% 0% / 0 !important;
}
```
Antigravity 2.0 前端采用现代 React 架构，下拉浮层基于 Radix UI / Shadcn UI 的 Popover、DropdownMenu、Select 与 cmdk 构建。这些浮层在挂载到根节点 Portal 时，外层容器类名大量继承了 `bg-popover`、`bg-card` 或直接依赖 CSS 变量，导致其背景被强制计算为 100% 完全透明。同时原生组件未自带 `backdrop-filter` 模糊，从而产生底层图文严重穿透的缺陷。

### 2. 深色模式原生 Hover 样式导致的突兀“黑底”
在 Antigravity 原生暗色风格中，各选项条目（`role="menuitem"`、`role="option"`、`button` 等）在鼠标悬停（Hover）、键盘选中（`data-highlighted`）或激活（`data-state="checked"`）时，使用了 Tailwind 的深色背景类（如 `bg-zinc-800`、`bg-neutral-800`、`bg-secondary`、`bg-accent` 等）。
当外层浮层卡片处于纯透明状态时，这种深色背景没有任何过渡缓冲，鼠标移入某一行就会瞬间呈现出突兀的黑色方块底色。

### 3. “背景出现放大动作”的真实根因（为什么工作区正常，项目与模型异常？）
通过注入前端实时探针捕获 DOM 运行日志，揭示了以下三大深层机制：

#### 机制 A：前序修复脚本正则未匹配导致底图重构未实际生效
* 在上一轮排查中，虽然识别到了 `background-attachment: fixed` 的危害并编写了替换脚本，但脚本中匹配 Section 2 结尾的正则表达式与 CSS 真实内容存在细微差异（`background-repeat` vs `background-color`），导致正则匹配失败，**本地与系统的主题 CSS 文件均未发生实质性改动，系统依然长期运行着原版 `background-attachment: fixed`**。

#### 机制 B：Radix 模态滚动锁 (Scroll Lock) 导致 Viewport 宽度突变
* **工作区选择器**：渲染为基础的 `<div role="listbox">`，不带有模态机制（`modal={false}`），展开时页面滚动条和视口宽度保持绝对静止，因此**完全没有放大或抖动**。
* **项目目录与模型选择器**：为标准 Radix Popover / DropdownMenu，默认启用了 `modal={true}`。展开时 Radix 会触发 `react-remove-scroll`，向 `document.body` 注入 `data-scroll-locked="1"` 并隐藏系统滚动条。
* 当背景图挂载在 `html, body, .h-screen.w-screen` 上时，视口宽度的 17px 抖动使得 `background-size: cover` 瞬间重新计算等比缩放比例，产生肉眼可见的“背景放大或缩放抽动”。

#### 机制 C：Chromium Skia 采样 Bug 与 Tailwind `zoom-in-95` 凸透镜放大镜效应
* 在 Chromium（Electron 44）中，当子元素具备 `backdrop-filter: blur(...)` 且祖先使用 `background-attachment: fixed` 时，Skia 图层合成器在 Windows 高分屏 DPI 缩放（125%/150%）下计算纹理采样坐标发生溢出放大。
* 同时，Radix Popper 子卡片附带 Tailwind 的 `animate-in`、`zoom-in-95`、`animate-slideIn`，其内部带有 `scale(0.95) -> scale(1.0)` 的缩放动画。当带有 16px 高斯模糊的浮层在 150ms 内从小变大时，背后的背景画面在视觉上随着边界扩张呈现出强烈的“放大镜推近”动作。

## 三、毛玻璃雾化与抗放大终极重构架构

针对以上根因，建立全维度的防御架构：

```
┌────────────────────────────────────────────────────────┐
│  1. 恒定视口底层 (body::before)                         │
│     - 100vw x 100vh 物理绝对定位，脱离 DOM 重排流       │
│     - 彻底抛弃 background-attachment: fixed            │
│     - translateZ(0) 独立硬件加速 GPU 纹理层              │
└──────────────────────────┬─────────────────────────────┘
                           │ 物理像素 1:1 绝对锁死
┌──────────────────────────▼─────────────────────────────┐
│  2. 视口尺寸锁 (Scroll Lock Defeat)                    │
│     - scrollbar-gutter: stable !important              │
│     - body[data-scroll-locked] margin/padding 清零     │
└──────────────────────────┬─────────────────────────────┘
                           │ 阻断宽度抖动
┌──────────────────────────▼─────────────────────────────┐
│  3. 浮层卡片 1:1 对齐毛玻璃 (Section 16)                │
│     - rgba(13, 21, 18, 0.32) 森林暗调微透底色          │
│     - backdrop-filter: blur(16px) saturate(130%)       │
│     - 条目悬停柔和白色微光，杜绝黑底                    │
└──────────────────────────┬─────────────────────────────┘
                           │ 独立绘制隔离
┌──────────────────────────▼─────────────────────────────┐
│  4. 全局动画矩阵清零 (Zero-Scale Defense)              │
│     - --tw-enter-scale: 1 !important                   │
│     - 重写 @keyframes slideIn / enter / zoomIn / exit  │
│     - 穿透清空全屏遮罩 Overlay 滤镜与动画              │
└────────────────────────────────────────────────────────┘
```

## 四、核心 CSS 规则实现

### 1. Section 2：独立 GPU 硬件加速固定图层重构

```css
/* ================= 2. 全局底图：独立 GPU 硬件加速固定图层 (彻底根除 Chromium backdrop-filter 放大 Bug 与滚动条抖动) ================= */
html {
    scrollbar-gutter: stable !important;
    background-color: transparent !important;
    background: transparent !important;
    overflow-x: hidden !important;
}

body,
.h-screen.w-screen,
#root,
.flex-1 {
    background-color: transparent !important;
    background: transparent !important;
    background-image: none !important;
}

body {
    margin-right: 0px !important;
    padding-right: 0px !important;
}

body[data-scroll-locked] {
    margin-right: 0px !important;
    padding-right: 0px !important;
    overflow: hidden !important;
}

/* 核心架构升级：使用独立固定图层 body::before 替代 background-attachment: fixed */
body::before {
    content: "" !important;
    position: fixed !important;
    top: 0 !important;
    left: 0 !important;
    right: 0 !important;
    bottom: 0 !important;
    width: 100vw !important;
    height: 100vh !important;
    z-index: -99999 !important;
    background-color: #0e1613 !important;
    background-image: 
        linear-gradient(rgba(0, 0, 0, 0.55), rgba(0, 0, 0, 0.55)),
        url("data:image/jpeg;base64,...") !important;
    background-size: cover !important;
    background-position: center center !important;
    background-repeat: no-repeat !important;
    pointer-events: none !important;
    transform: translateZ(0) !important;
    will-change: transform !important;
}
```

### 2. Section 16：新对话选择器菜单极致轻透雾化与全套动画抹平

```css
/* 1. Radix Popper 外层定位容器：禁用任何缩放与位移动画，只保留 Popper 自身的绝对坐标 */
[data-radix-popper-content-wrapper],
div[role="presentation"][data-side],
div[data-side],
[data-portal] {
    animation: none !important;
    animation-duration: 0s !important;
    animation-name: none !important;
    transition: none !important;
    --tw-enter-scale: 1 !important;
    --tw-exit-scale: 1 !important;
    --tw-scale-x: 1 !important;
    --tw-scale-y: 1 !important;
    --tw-enter-translate-x: 0 !important;
    --tw-enter-translate-y: 0 !important;
}

/* 2. 彻底禁用全屏遮罩层 (Overlay) 滤镜与动画 */
[data-radix-dropdown-menu-overlay],
[data-radix-popover-overlay],
[data-radix-select-overlay],
[data-radix-menu-overlay],
[data-radix-dialog-overlay] {
    background-color: transparent !important;
    background: transparent !important;
    backdrop-filter: none !important;
    -webkit-backdrop-filter: none !important;
    animation: none !important;
    transition: none !important;
}

/* 3. 下拉菜单真实浮层卡片：1:1 对齐主对话框的轻盈透明雾化核心 */
.animate-slideIn,
[class*="animate-slideIn"],
[class*="animate-in"],
[class*="zoom-in"],
[data-state="open"],
[data-state="closed"],
div[role="presentation"][data-side] > div,
div[data-side] > div,
[data-radix-popper-content-wrapper] > div,
[data-radix-menu-content],
[data-radix-dropdown-menu-content],
[data-radix-popover-content],
[data-radix-select-content],
div[role="menu"],
div[role="listbox"]:not([data-mention-menu]) {
    background-color: rgba(13, 21, 18, 0.32) !important;
    background: rgba(13, 21, 18, 0.32) !important;
    backdrop-filter: blur(16px) saturate(130%) !important;
    -webkit-backdrop-filter: blur(16px) saturate(130%) !important;
    border: 1px solid rgba(255, 255, 255, 0.16) !important;
    border-radius: 14px !important;
    box-shadow: 0 8px 32px rgba(0, 0, 0, 0.25) !important;
    overflow: hidden !important;

    /* 独立图层与硬件加速隔离：严禁任何 scale 放大矩阵 */
    transform: translateZ(0) !important;
    -webkit-transform: translateZ(0) !important;
    transform-origin: unset !important;
    animation: none !important;
    animation-name: none !important;
    animation-duration: 0s !important;
    --tw-enter-scale: 1 !important;
    --tw-exit-scale: 1 !important;
    --tw-scale-x: 1 !important;
    --tw-scale-y: 1 !important;
    --tw-enter-translate-x: 0 !important;
    --tw-enter-translate-y: 0 !important;
    transition: opacity 0.12s ease-out !important;
    isolation: isolate !important;
}

/* 从源头重写 keyframes 动画，彻底抹平全局所有 scale 缩放矩阵 */
@keyframes slideIn { from { opacity: 0; transform: translateZ(0) !important; } to { opacity: 1; transform: translateZ(0) !important; } }
@keyframes enter   { from { opacity: 0; transform: translateZ(0) !important; } to { opacity: 1; transform: translateZ(0) !important; } }
@keyframes zoomIn  { from { opacity: 0; transform: translateZ(0) !important; } to { opacity: 1; transform: translateZ(0) !important; } }
@keyframes exit    { from { opacity: 1; transform: translateZ(0) !important; } to { opacity: 0; transform: translateZ(0) !important; } }
@keyframes zoomOut { from { opacity: 1; transform: translateZ(0) !important; } to { opacity: 0; transform: translateZ(0) !important; } }

/* 4. 条目悬停柔和白色微光 */
[role="menuitem"]:hover,
[role="menuitem"][data-highlighted],
div[role="menu"] [role="option"]:hover,
div[role="menu"] [role="option"][data-highlighted] {
    background-color: rgba(255, 255, 255, 0.12) !important;
    background: rgba(255, 255, 255, 0.12) !important;
    border: 1px solid rgba(255, 255, 255, 0.10) !important;
    color: #ffffff !important;
}
```
