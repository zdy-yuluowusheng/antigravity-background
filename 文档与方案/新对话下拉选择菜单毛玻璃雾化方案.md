# 新对话窗口下拉选择菜单与交互审批卡片毛玻璃雾化方案

本文档记录了在 Antigravity 2.0 桌面端中，针对以下交互区域的成因剖析、技术方案设计与落地实施：
1. **新对话窗口选择器菜单**：项目目录、模型选择与工作区选择下拉框轻透雾化与背景抗放大架构；
2. **输入框 @ 引用与 / 命令弹出菜单**：对齐输入框通透毛玻璃雾化（解决纯透明与太黑的失衡）；
3. **输入框内部黑条与残影占位圈消除**：穿透净化原生深色类名与空按钮；
4. **对话流交互审批卡片（Permission & Question Prompts）**：消除鼠标悬停在选项上的纯黑长条，重塑为柔和白色半透明微光。

## 二、最新缺陷成因深度剖析

### 1. 对话流审批卡片条目鼠标悬停“纯黑长条”成因（图一）
通过检索 Antigravity 核心源码 `workbench.desktop.main.js`，定位到交互审批与单选问题组件（`ask_permission` / `ask_question`）：
```javascript
// 选项 class 构造函数
zsa = (t, e = "items-center", i = !1) => 
  `flex ${i ? "opacity-50 cursor-not-allowed" : "cursor-pointer"} ${e} gap-2 rounded-lg pr-2 pl-1.5 py-1 text-sm focus-within:outline-none border ${t ? "bg-secondary border-border" : i ? "!border-transparent" : "hover:bg-secondary !border-transparent"}`
```
* **根因**：每个选项为一个 `<label>`，在鼠标悬停时附带 `hover:bg-secondary`，选中时附带 `bg-secondary`。原生深色模式下，`bg-secondary` 呈现为死黑底色 `rgb(39, 39, 42)`。在全透明毛玻璃森林背景衬托下，鼠标悬停时会在整行突兀地浮现出一个深沉死板的黑色长条。

### 2. 输入框上方候选项列表在“太黑”与“纯透明”之间的成因（图二）
* **0.78 浓黑（历史原因）**：最初为了避免底层文字穿透，设置了 `rgba(13, 21, 18, 0.78)`，透度仅 22%，视觉上太厚太黑。
* **0.32 纯透明（上一轮原因）**：直接调至 0.32 后，在较小尺寸卡片下暗度不足；且卡片内部存在 `isolation: isolate` 隔离属性，阻断了 Chromium 渲染引擎向上对背景进行高斯模糊采样，导致卡片背后的松树树枝清晰锐利透出，完全无雾化。
* **对齐方案**：对齐主输入框的实际质感，采用微暗半透明底色 `rgba(13, 21, 18, 0.58)` + `backdrop-filter: blur(16px)`，并移除 `isolation: isolate`，实现与主对话框浑然一体的优雅雾化。

### 3. 输入框内部 @ 下方残留小圆圈成因（图二）
* 在富文本输入中键入 `@` 时，编辑器生成了一个用于触发选择的内嵌空按钮（`w: 24, h: 24, text: ""`）。被局部规则赋予了微光白边和背景，在加号上方暴露出一个小圆角矩形。通过对无文本内容的空按钮强制透底予以彻底清除。
