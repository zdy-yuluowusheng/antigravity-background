# 输入框候选项列表（@ 与 /）毛玻璃雾化方案

本文档详细记录了在 Antigravity 2.0 聊天对话框中，针对用户在主输入框输入 `@`（引用文件、变量、会话）或 `/`（斜杠快捷命令）时，弹出的候选项菜单列表（Candidate / Mention / Slash Command Popover）与底层聊天流文字穿透重叠缺陷的成因分析、DOM 逆向排查、样式方案设计与运行时生效验证。

---

## 一、问题背景与现象

在应用了晨雾森林毛玻璃主题后，用户在底部对话框进行操作时反馈：
> “目前使用 @ 或者 / 的时候会在对话框上方列出候选项，这个候选项列表也做雾化处理吧，不然和下方的文字重叠起来看不太清楚。”

### 1. 缺陷视觉表现
* 当用户在底部输入框（`[data-testid="agent-input-box"]`）中键入 `@` 或 `/` 时，输入框上方会立即升起一个候选项目录列表（包含 `RECENTLY OPENED`、`FILE RESULTS` 及各类代码文件/命令条目）。
* 该弹出层背景呈现 **100% 绝对纯透明**，没有任何背景色或高斯模糊遮罩。
* 导致底层对话流中的长文字（例如用户提问、AI 回答、文件变更提示栏 `4 files changed` 等）直接透过候选项列表清晰呈现，候选项文字与底层对话文字发生严重的位置重叠，形成杂乱无章的“字叠字”乱码视觉缺陷，严重降低候选项的可读性与交互体验。

---

## 二、DOM 结构逆向与成因深度剖析

通过在 BetterGravity 插件运行环境中动态注入 DOM 监听与触发钩子，精准抓取了输入框 `@` 与 `/` 触发时生成的实际 DOM 树：

### 1. 候选项浮层容器层级
```html
<div data-testid="agent-input-box">
  <!-- 输入框外框结构 -->
  <div class="relative ...">
    <!-- 候选项列表容器 (绝对定位在输入框上方 bottom-full) -->
    <div 
      role="listbox" 
      aria-label="Mentions" 
      data-mention-menu="" 
      class="absolute left-0 w-full bottom-full mb-2 bg-card rounded-2xl border z-30 overflow-hidden shadow-md">
      
      <!-- 内部限高滚动包装器 -->
      <div class="max-h-[200px] overflow-y-auto w-full py-1 rounded-2xl">
        <!-- 候选项条目 -->
        <div id="typeahead-item-0" role="option" aria-selected="true">
          <div class="flex w-full px-2 py-1 items-center gap-2 cursor-pointer bg-secondary">
            <span class="text-secondary-foreground flex items-center shrink-0">
              <img src="/symbols-icons/icons/files/js.svg" width="16" height="16" />
            </span>
            <span class="text-xs shrink-0" data-testid="menu-option-label">
              <span>探查候选项菜单结构.js</span>
            </span>
            <span class="text-xs opacity-50 min-w-0 shrink-[8] truncate" data-testid="menu-option-description">
              逆向与调试工具
            </span>
          </div>
        </div>
        <!-- 更多候选项条目... -->
      </div>
    </div>
  </div>
</div>
```

### 2. 缺陷根本原因排查
1. **全局卡片变量穿透**：
   在主题的第 1 节中，为了实现整体通透感，将 `--card: 0 0% 0% / 0 !important;` 设为了完全透明。
2. **输入框内级联透明规则泛化**：
   在主题的第 10 节规则中，原规则声明为：
   ```css
   [data-testid="agent-input-box"] .bg-card,
   [data-testid="agent-input-box"] [class*="bg-card"] {
       background-color: transparent !important;
       background: transparent !important;
       box-shadow: none !important;
   }
   ```
   由于候选项容器 `<div data-mention-menu class="... bg-card ...">` 挂载在 `[data-testid="agent-input-box"]` 的内部子树中，恰好带有 `bg-card` 类名，导致它被直接强制穿透为 100% 透明，同时原生组件未自带 `backdrop-filter` 模糊，从而导致文字穿透重叠。
3. **按钮胶囊边框污染**：
   第 10 节对输入框内 `.bg-secondary` 设置了药丸按钮样式的 1px 细边框，导致候选项列表中的被选条目（同样使用了 `.bg-secondary`）带有突兀的多余外边框。

## 三、毛玻璃雾化设计方案

为了与晨雾森林主题的通透高级质感、吸顶卡片（Section 7）以及底部输入框外框（Section 10）的几何设计保持高度一致，制定了如下穿透与优化方案：

### 1. 视觉设计原则
* **阻隔底层文字**：采用暗调半透明森林底色 `rgba(13, 21, 18, 0.78)`，结合 `backdrop-filter: blur(16px) saturate(130%)` 深度高斯模糊，彻底消除底层穿透文字的边缘干扰。
* **几何外形对齐**：圆角采用与输入框一致的 `border-radius: 16px`，边框采用精致高透白微光 `border: 1px solid rgba(255, 255, 255, 0.16)`。
* **立体层级呈现**：添加 `box-shadow: 0 12px 36px rgba(0, 0, 0, 0.35)` 柔和漫反射环境阴影，使菜单自然悬浮于画板上方。
* **条目交互微光**：选中项（`aria-selected="true"`）呈现柔和白色半透明微光 `rgba(255, 255, 255, 0.14)`，悬停时平滑渐变至 `rgba(255, 255, 255, 0.10)`，并消除多余按钮边框。

## 四、核心 CSS 规则实现

在 [`主题样式/晨雾森林毛玻璃主题.css`](file:///d:/work/antigravity-background/%E4%B8%BB%E9%A2%98%E6%A0%B7%E5%BC%8F/%E6%99%A8%E9%9B%BE%E6%A3%AE%E6%9E%97%E6%AF%9B%E7%8E%BB%E7%92%83%E4%B8%BB%E9%A2%98.css) 中实施如下改造：

### 1. 修改第 10 节（安全排除候选项菜单）
```css
/* 保持主输入框底层卡片透明，与晨雾背景自然融合 (排除上方浮动候选项列表) */
[data-testid="agent-input-box"],
[data-testid="agent-input-box"] .bg-card:not([data-mention-menu]):not([class*="bottom-full"]),
[data-testid="agent-input-box"] .bg-card-border:not([data-mention-menu]):not([class*="bottom-full"]),
[data-testid="agent-input-box"] [class*="bg-card"]:not([data-mention-menu]):not([class*="bottom-full"]),
[data-testid="agent-input-box"] [class*="bg-card-border"]:not([data-mention-menu]):not([class*="bottom-full"]) {
    background-color: transparent !important;
    background: transparent !important;
    box-shadow: none !important;
}
```

### 2. 追加第 15 节专用规则
```css
/* ================= 15. 输入框 @ 与 / 候选项列表（Mention / Slash Commands）：精致毛玻璃雾化浮层 ================= */

/* 1. 候选项菜单外层浮动卡片容器：毛玻璃雾化核心 */
[data-mention-menu],
div[role="listbox"][data-mention-menu],
div[role="listbox"][aria-label="Mentions"],
[data-testid="agent-input-box"] [data-mention-menu],
[data-testid="agent-input-box"] div[role="listbox"][class*="bottom-full"],
[data-testid="agent-input-box"] div[class*="bottom-full"][class*="bg-card"],
[data-testid="agent-input-box"] div[role="listbox"],
[data-testid*="mention-menu"],
[data-testid*="slash-menu"],
[data-testid*="command-menu"],
#typeahead-menu {
    background-color: rgba(13, 21, 18, 0.78) !important;
    background: rgba(13, 21, 18, 0.78) !important;
    backdrop-filter: blur(16px) saturate(130%) !important;
    -webkit-backdrop-filter: blur(16px) saturate(130%) !important;
    border: 1px solid rgba(255, 255, 255, 0.16) !important;
    border-radius: 16px !important;
    box-shadow: 0 12px 36px rgba(0, 0, 0, 0.35) !important;
    overflow: hidden !important;
}

/* 2. 候选项列表内层滚动容器与遮罩：通透无边框，保持一致圆角与间距 */
[data-mention-menu] > div,
[data-testid="agent-input-box"] [data-mention-menu] > div,
[data-testid="agent-input-box"] div[role="listbox"] > div {
    background-color: transparent !important;
    background: transparent !important;
    border: none !important;
    box-shadow: none !important;
}

/* 3. 候选项各行条目（Item）项容器：平时纯净通透，杜绝多层背景叠加 */
[data-mention-menu] [role="option"],
[data-testid="agent-input-box"] [data-mention-menu] [role="option"] {
    background-color: transparent !important;
    background: transparent !important;
}

/* 4. 候选项条目内层交互胶囊：平滑圆角与自适应微光反馈 */
[data-mention-menu] [role="option"] > div,
[data-testid="agent-input-box"] [data-mention-menu] [role="option"] > div {
    border: 1px solid transparent !important;
    border-radius: 8px !important;
    transition: background-color 0.15s ease, border-color 0.15s ease !important;
}

/* 5. 当前键盘选中/激活的候选项 (aria-selected="true" 或 bg-secondary) */
[data-mention-menu] [role="option"][aria-selected="true"] > div,
[data-testid="agent-input-box"] [data-mention-menu] [role="option"][aria-selected="true"] > div,
[data-mention-menu] [role="option"] > div.bg-secondary,
[data-testid="agent-input-box"] [data-mention-menu] .bg-secondary {
    background-color: rgba(255, 255, 255, 0.14) !important;
    border: 1px solid rgba(255, 255, 255, 0.12) !important;
}

/* 6. 鼠标悬停时的候选项行微光高亮 */
[data-mention-menu] [role="option"] > div:hover,
[data-testid="agent-input-box"] [data-mention-menu] [role="option"] > div:hover {
    background-color: rgba(255, 255, 255, 0.10) !important;
    border: 1px solid rgba(255, 255, 255, 0.08) !important;
}

/* 7. 候选项分类标题与次要信息（如 RECENTLY OPENED, FILE RESULTS 等大写微光小字）清晰度优化 */
[data-mention-menu] [class*="opacity-50"],
[data-mention-menu] [data-testid="menu-option-description"] {
    color: rgba(255, 255, 255, 0.65) !important;
}

/* 8. 候选项标题与主文件名文字高亮呈现 */
[data-mention-menu] [data-testid="menu-option-label"],
[data-mention-menu] [data-testid="menu-option-label"] span {
    color: #ffffff !important;
    font-weight: 500 !important;
}
```

## 五、生效验证结果

运行 [`逆向与调试工具/验证候选项列表样式生效.js`](file:///d:/work/antigravity-background/%E9%80%86%E5%90%91%E4%B8%8E%E8%B0%83%E8%AF%95%E5%B7%A5%E5%85%B7/%E9%AA%8C%E8%AF%81%E5%80%99%E9%80%89%E9%A1%B9%E5%88%97%E8%A1%A8%E6%A0%B7%E5%BC%8F%E7%94%9F%E6%95%88.js)，在 Antigravity 实际窗口中捕获到的实时计算样式（ComputedStyle）如下：

```json
{
  "found": true,
  "tagName": "div",
  "className": "absolute left-0 w-full bottom-full mb-2 bg-card rounded-2xl border z-30 overflow-hidden shadow-md",
  "computedStyles": {
    "backgroundColor": "rgba(13, 21, 18, 0.78)",
    "backdropFilter": "blur(16px) saturate(1.3)",
    "border": "0.666667px solid rgba(255, 255, 255, 0.16)",
    "borderRadius": "16px",
    "boxShadow": "rgba(0, 0, 0, 0.35) 0px 12px 36px 0px",
    "overflow": "hidden"
  },
  "optionStyles": {
    "backgroundColor": "rgba(255, 255, 255, 0.14)",
    "borderRadius": "8px",
    "border": "0.666667px solid rgba(255, 255, 255, 0.12)"
  }

```

各项指标 100% 达成设计预期：
1. **背景色与模糊度**：`backgroundColor` 为 `rgba(13, 21, 18, 0.78)`，`backdropFilter` 达到 `blur(16px)`，底层文字被完全平滑虚化与暗调阻隔。
2. **几何外观**：`borderRadius` 达到 `16px`，`border` 精致微光，与底部输入框达到 1:1 几何呼应。
3. **条目交互反馈**：选项高亮底色与圆角完全呈现微光风格，彻底消除任何原生的生硬黑块与多余边框。
