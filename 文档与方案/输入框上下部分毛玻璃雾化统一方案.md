# 输入框上下部分毛玻璃雾化统一方案

## 1. 问题现象与根因诊断

### 1.1 问题现象
在对话主输入框中，卡片整体出现了明显的上下割裂与断层现象：
- **上半部分（文本输入区域）**：呈现出优雅的深绿色晨雾毛玻璃雾化效果，背后的松树等细节被柔和化开；
- **下半部分（操作底栏工具栏）**：包含模型选择器按钮（`Gemini 3.8 Flash High`）、工作区环境按钮（`Local`）、麦克风与发送按钮的整块区域，呈现为 100% 绝对纯透明，清晰露出了后方壁纸中锐利的松树针叶；
- **分界线明显**：上下两部分被水平切开，视觉上形成了“上半截雾化、下半截镂空”的不协调观感。

---

### 1.2 源码结构根因定位
通过深入逆向 Antigravity 核心前端程序（`workbench.desktop.main.js`）中的输入框组件 `V5n`：
```html
<!-- 输入框整体外壳 -->
<div id="CMu" class="relative flex flex-col p-px rounded-2xl bg-card-border">
  <!-- 上半部分：文本输入卡片 -->
  <div class="relative flex flex-col gap-0 p-1 rounded-[calc(theme(borderRadius.2xl)-1px)] bg-card">
    ...文本框 textarea / contenteditable...
  </div>
  <!-- 下半部分：操作底栏工具栏组件 (TMu) -->
  <div class="flex w-full items-center justify-between gap-1 p-0.5">
    ...模型选择器按钮、Local按钮、语音、发送等...
  </div>
</div>
```

- **割裂成因**：
  在之前的局部调整中，毛玻璃属性被单独施加在 `[data-testid="agent-input-box"] .bg-card-border > div.bg-card` 上。由于 `div.bg-card` 仅仅对应上半截的文本输入区，下半截的操作底栏组件（`TMu`）并未包裹在 `div.bg-card` 内部，导致下半截区域完全失去了 `backdrop-filter` 模糊采样与背景底色，直接向后穿透透底，造成了上下两半的视觉撕裂。

---

## 2. 解决方案与全量实施

### 2.1 提升毛玻璃至整体外壳容器
将毛玻璃滤镜与暗绿雾化底色统一度量在外层整体容器 `.bg-card-border` 上：
```css
/* 为主输入框整体卡片赋予统一连续的晨雾毛玻璃雾化、精致高透外边框与自然微暗底色 */
[data-testid="agent-input-box"] .bg-card-border:not([data-mention-menu]):not([class*="bottom-full"]) {
    border: 1px solid rgba(255, 255, 255, 0.16) !important;
    border-radius: 16px !important;
    backdrop-filter: blur(16px) saturate(130%) !important;
    -webkit-backdrop-filter: blur(16px) saturate(130%) !important;
    background-color: rgba(13, 21, 18, 0.22) !important;
    background: rgba(13, 21, 18, 0.22) !important;
    box-shadow: 0 8px 32px rgba(0, 0, 0, 0.20) !important;
    overflow: visible !important;
}
```

### 2.2 解构子容器局部重复模糊
清空上半截 `div.bg-card` 与下半截工具栏的局部背景与滤镜，确保它们内部纯净透底：
```css
/* 确保内部各子区域背景纯净透底，杜绝局部双重叠加导致不均 */
[data-testid="agent-input-box"] .bg-card-border > div,
[data-testid="agent-input-box"] .bg-card-border > div.bg-card,
[data-testid="agent-input-box"] .bg-card-border form,
[data-testid="agent-input-box"] .bg-card-border [class*="items-center"]:not(button):not(a):not(span) {
    backdrop-filter: none !important;
    -webkit-backdrop-filter: none !important;
    background-color: transparent !important;
    background: transparent !important;
}
```

### 2.3 严密保持候选项菜单独立遮盖
上方浮动弹出的 `@` 与 `/` 候选项列表保持独立的 `rgba(13, 21, 18, 0.82) !important` + `blur(20px)` + `isolation: isolate` + `z-index: 99999`，不受输入框内部任何透底规则影响，依然稳定彻底阻隔后方文字。

---

## 3. 验收标准与效果对照

| 对比维度 | 修复前 | 修复后 |
| :--- | :--- | :--- |
| **上半部分** | 雾化绿色毛玻璃 | 保持柔和深绿晨雾毛玻璃雾化 |
| **下半部分** | 纯透明直穿，露出生硬松针 | **与上半部分完全统一**，呈现无缝连贯的毛玻璃雾化 |
| **整体感** | 上下断层割裂 | 浑然一体，四周 16px 圆角高透光外框连续包覆 |
| **候选项列表** | 独立遮盖正常 | 保持 0.82 扎实遮盖力，完全阻隔后方文字 |
