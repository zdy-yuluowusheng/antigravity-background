# 输入框提及菜单（@与/）与模型选择样式全量统一方案

## 1. 问题现象与根因深度剖析

### 1.1 用户反馈现象
在 Antigravity 主对话框中：
1. **模型选择器（Model Picker）**：呈现出极佳的暗绿毛玻璃遮蔽效果，浮层卡片平整盖住后方正文，后方的白色文字被彻底化开遮蔽，悬停时条目呈现细腻高雅的白色微光，用户高度认可并作为统一样式的基准标准。
2. **输入框 `@`（引用）或 `/`（斜杠命令）候选项列表**：后方的对话历史文字（如操作说明、审批文本）几乎毫无阻挡、清清楚楚地透过了候选列表，导致前后台文字严重穿透叠合（“字叠字”），严重影响阅读和选项点击。

---

### 1.2 源码层级与渲染机制深层根因定位
通过深入逆向 Antigravity 核心前端程序 (`workbench.desktop.main.js`) 与 Chromium 渲染树合成规则，定位到了以下核心根因：

1. **选择器割裂与人为排除 (`:not([data-mention-menu])`)**：
   - 模型选择器挂载于 `document.body` 顶层的 Radix Popper（`[data-radix-popper-content-wrapper]`）；
   - `@`/`/` 候选项列表由组件 `lsa` / `uFu` 渲染：
     ```html
     <div role="listbox" aria-label="Mentions" data-mention-menu="" class="absolute left-0 w-full bottom-full mb-2 bg-card rounded-2xl border z-30 overflow-hidden shadow-md">
     ```
   - 原样式表中在 Section 16 专门加入了大量 `:not([data-mention-menu])` 排除性声明，导致输入框上方候选卡片被彻底排斥在模型选择器的最高优先级规则之外。

2. **祖先层级 `backdrop-filter` 导致的几何溢出采样失效**：
   - 候选菜单并不是挂在 `document.body`，而是通过 React Portal（`bE.current`）作为子节点内嵌在输入框外壳 `.bg-card-border` 中；
   - 原 Section 10 对父级 `.bg-card-border` 应用了 `backdrop-filter: blur(12px)`；
   - **Chromium 合成层关键限制**：当父级容器带有 `backdrop-filter` 形成独立 RenderLayer 时，子元素凭借 `position: absolute; bottom: 100%` 飞出父容器顶部几何边界后，其自身的 `backdrop-filter` 无法采样父级外部的页面内容，导致高斯模糊对上方文本彻底失效，所有文字清澈直穿。

3. **光学密度（遮盖力）与图层隔离缺失**：
   - 原候选菜单底色透明度过高，且缺乏 `isolation: isolate` 与硬件加速层，一旦遇到浅色或白色高亮正文，便无法形成扎实的光学阻断。

---

## 2. 核心解决方案与架构重塑

### 2.1 解除父级阻断（解构 Section 10）
- 将 `.bg-card-border` 外框容器自身的 `backdrop-filter` 移除，仅保留精致高透的玻璃外边框与投影；
- 将输入框底部的毛玻璃仅精准限制在真实的文本表单卡片 `.bg-card-border > div.bg-card` 内；
- 彻底解放子元素 `[data-mention-menu]`，使其飞出边界后能够完整对后方整屏内容进行深度模糊采样。

### 2.2 Section 15 与 Section 16 全面统一合并
彻底删除所有 `:not([data-mention-menu])` 排除条件，将模型选择、项目目录、工作区选择以及 `@`/`/` 候选项列表合并至同一套最高优先级毛玻璃规范：
- **背景底色**：统一采用 `rgba(13, 21, 18, 0.82) !important`（扎实暗绿磨砂底色，提供强大的光学遮盖力）；
- **毛玻璃滤镜**：统一采用 `backdrop-filter: blur(20px) saturate(140%) !important`；
- **边框与圆角**：统一为 `1px solid rgba(255, 255, 255, 0.16) !important`，圆角 `14px`；
- **图层提权**：赋予 `isolation: isolate !important`、`transform: translateZ(0) !important` 与 `z-index: 99999 !important`，确保无论在 DOM 内部还是外部均拥有独立的最高合成层级。

### 2.3 条目悬停与微光 100% 统一
- 条目（Item）平时保持 100% 纯净通透，杜绝多层叠加；
- 鼠标悬停（Hover）、键盘选中（`[aria-selected="true"]`）、以及原生 `bg-secondary` 统一覆盖为：
  ```css
  background-color: rgba(255, 255, 255, 0.12) !important;
  border: 1px solid rgba(255, 255, 255, 0.10) !important;
  color: #ffffff !important;
  ```
