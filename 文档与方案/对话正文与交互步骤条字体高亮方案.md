# Antigravity 对话正文与交互步骤条字体高亮优化方案

## 一、背景与问题根因

在引入晨雾森林透明毛玻璃主题后，用户对比了 **ChatGPT 桌面端** 与 **Antigravity 桌面端** 的界面文字表现，指出了两项关键体验差异：

1. **整体字体明度差异**：
   * **ChatGPT**：对话流正文默认采用了纯白亮色（`rgba(245, 247, 250, 0.95)`），在透光的毛玻璃风景壁纸衬托下，对比度鲜明、文字饱满锐利。
   * **Antigravity**：底层基于 Tailwind CSS 构建深色模式，大量段落、列表、说明文本默认继承了次级文本类 `text-muted-foreground`（大约只有 60%~70% 的低饱和灰白色），在背景壁纸透出后对比度不足，视觉上显得**暗淡、发虚**。

2. **交互步骤条（Tab）跳变与频闪**：
   * 在执行步骤（`Ran 命令`、`Worked for`、`Thought for`、折叠步骤等）中，旧版主题仅在 `:hover` 悬停伪类中写了 `color: #ffffff !important`，而平时未设置颜色（继承了原生的灰暗文字）。
   * 这导致了**平时文字暗淡，鼠标悬停时文字猛然跳亮**，存在视觉跳变频闪感。

---

## 二、优化目标与交互规范（再次调降 5% 后的精修明度分配）

根据用户的精细调优需求，各区域字体明度再次统一调降 5 个百分点，达到极致柔和与细腻通透的平衡：

| 界面区域 | 基准满分 (100) 对应亮度 | 具体 CSS 色值 | 视觉特性与设计考量 |
| :--- | :---: | :--- | :--- |
| **步骤条 / Tab（Ran 命令、折叠条）** | **90** | `rgba(255, 255, 255, 0.90)` | 平时默认 90 明度白亮，hover 字体亮度保持不变，仅靠微光背景反馈。 |
| **各级标题与文件变更状态条** | **90** | `rgba(255, 255, 255, 0.90)` | 清晰醒目，重点突出，白而不眩目。 |
| **主对话正文（AI 段落、列表、代码说明）** | **85** | `rgba(255, 255, 255, 0.85)` | 85% 柔和自然阅读亮度，长时间观看极佳护眼体验。 |
| **左侧侧边栏会话标题** | **80** | `rgba(255, 255, 255, 0.80)` | 层次自然，与风景壁纸完美融合。 |
| **次级辅助弱化文字（时间戳、小提示）** | **75** | `rgba(255, 255, 255, 0.75)` | 保持次级信息清晰可见，层级分明。 |

## 四、验证与生效方法
