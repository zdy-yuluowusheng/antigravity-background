# Antigravity 对话正文与交互步骤条字体高亮优化方案

## 一、背景与问题根因

在引入晨雾森林透明毛玻璃主题后，用户对比了 **ChatGPT 桌面端** 与 **Antigravity 桌面端** 的界面文字表现，指出了两项关键体验差异：

1. **整体字体明度差异**：
   * **ChatGPT**：对话流正文默认采用了纯白亮色（`rgba(245, 247, 250, 0.95)`），在透光的毛玻璃风景壁纸衬托下，对比度鲜明、文字饱满锐利。
   * **Antigravity**：底层基于 Tailwind CSS 构建深色模式，大量段落、列表、说明文本默认继承了次级文本类 `text-muted-foreground`（大约只有 60%~70% 的低饱和灰白色），在背景壁纸透出后对比度不足，视觉上显得**暗淡、发虚**。

2. **交互步骤条（Tab）跳变与频闪**：
   * 在执行步骤（`Ran 命令`、`Worked for`、`Thought for`、折叠步骤等）中，旧版主题仅在 `:hover` 悬停伪类中写了 `color: #ffffff !important`，而平时未设置颜色（继承了原生的灰暗文字）。
   * 这导致了**平时文字暗淡，鼠标悬停时文字猛然跳亮**，存在视觉跳变频闪感。

---

## 二、优化目标与交互规范

1. **平时状态默认纯白高亮**：
   * 将命令行步骤条、折叠卡片、工作时长以及子项命令行内部的所有代码文本、参数与折叠箭头，默认直接赋予 `color: #ffffff !important;`。
   * 使步骤条平时即拥有 100% 的明亮清晰度，彻底告别低对比度灰暗。

2. **悬停（hover）状态保持字体亮度恒定**：
   * 鼠标悬停到步骤条时，字体颜色保持纯白不变（无需跳变与频闪）。
   * 纯粹依靠外层 Tab 容器的**白色半透明微光浮层**（`rgba(255, 255, 255, 0.12)`）与**高亮微光边框**（`rgba(255, 255, 255, 0.25)`）来呈现优雅的选中反馈。

3. **全局对话流正文与侧边栏明度联动拉升**：
   * 将对话区 AI 回复段落 `<p>`、列表 `<li>`、富文本 `.prose` 的字色统一拉升至 `rgba(248, 250, 252, 0.95)`；
   * 将各级小标题 `<h1>`~`<h6>` 与文件变更条 `files-changed-header` 拉升至 `#ffffff`；
   * 开启 `-webkit-font-smoothing: antialiased;` 抗锯齿渲染，解决 Windows 环境下 Chromium 内核字体边缘模糊的问题；
   * 侧边栏会话历史条目文字同步拉升至 `rgba(255, 255, 255, 0.90)`。

### 2. 对话流正文高对比度增强（Section 5）

```css
/* 对话正文通用文字对比度与清晰度增强 (白亮字体，优雅阅读，对齐 ChatGPT 亮白质感) */
[data-testid="conversation-view"],
[data-testid="conversation-view"] p,
[data-testid="conversation-view"] li,
[data-testid="conversation-view"] .prose,
[data-testid="conversation-view"] [class*="prose"] {
    color: rgba(248, 250, 252, 0.95) !important;

[data-testid="conversation-view"] h1,
[data-testid="conversation-view"] h2,
[data-testid="conversation-view"] h3,
[data-testid="conversation-view"] h4,
[data-testid="conversation-view"] h5,
```

## 四、验证与生效方法

1. **部署状态**：已通过自动化脚本完成更新并全量同步至系统目录 `%APPDATA%\BetterGravity\themes\晨雾森林毛玻璃主题.css`。
2. **热重载生效**：在正在运行的 Antigravity 客户端窗口中按下快捷键 **`Ctrl + R`**，样式将即刻生效。
