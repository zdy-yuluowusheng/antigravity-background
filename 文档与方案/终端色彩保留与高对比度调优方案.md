# Antigravity 终端文字高亮度保持与全量 ANSI 色彩还原方案

## 一、问题背景与现象

在先前对 Antigravity 客户端右侧辅助面板（总览、审查、终端）进行字体提亮（提升约 20% 明度）时，用户反馈：
- 终端普通文字确实变亮清晰了；
- 但原有终端输出中具备语法高亮与语义标识的颜色（如 PowerShell 脚本的高亮黄色、图片路径的青色、`[成功]` 的绿色、报错的红色等）均被强制覆盖成了同一种纯白色，丢失了色彩区分度。

---

## 二、深度逆向与根因分析

通过在渲染层对 Antigravity 的 xterm DOM 渲染器进行运行时结构探查，发现以下关键原因：

1. **渲染器架构与类名机制**：
   - Antigravity 终端底层采用的是 **xterm.js DOM 渲染器**（`xterm-dom-renderer`）。
   - 在控制台中输出彩色字符时，xterm 会在文本 `span` 标签上标记 **`xterm-fg-X`** 类名（例如 `xterm-fg-1` 红色、`xterm-fg-2` 绿色、`xterm-fg-3` 黄色、`xterm-fg-6` 青色、`xterm-fg-11` 亮黄色等）。
   - 而普通未指定色彩的文本 `span` 没有 `xterm-fg-` 类名，或者是 `xterm-fg-7`（默认白）/ `xterm-fg-15`（亮白）。

2. **全局强效覆盖冲突（!important）**：
   - 原提亮规则中使用了 `:not([class*="ansi-green"]):not([class*="ansi-yellow"])...` 过滤伪类；
   - 但因为 xterm 真实使用的色彩类名是 `xterm-fg-X` 而非 `ansi-X`，导致所有带颜色的 `span` 全部被该规则命中；
   - 叠加 `color: rgba(255, 255, 255, 0.96) !important;` 声明后，将原生未带 `!important` 的色彩规则强行覆盖，造成全终端白化。

---

## 三、精准隔离与高明度调优策略

本次优化采取 **“精准白度隔离 + 现代高饱和度 ANSI 调色板”** 的双重策略：

### 1. 普通文字精准提亮（保留 96% 极清亮白）
- 仅针对没有 `xterm-fg-` 前景色类名且无行内 `color` 样式的普通文字应用 `rgba(255, 255, 255, 0.96)`；
- 避免对任何携带颜色标识的元素施加纯白覆盖。

### 2. ANSI 色彩全量还原并适配毛玻璃底图
原生的 VT100 终端颜色（如纯暗绿 `rgb(78, 154, 6)`、暗红 `rgb(204, 0, 0)`）在深色毛玻璃背景下偏沉偏暗。我们将其优化为现代高饱和度、高透亮度的调色方案：

| :--- | :--- | :--- | :--- | :--- |

## 四、核心 CSS 规则实现

```css
/* 11.6 终端面板 (Terminal / xterm)：控制台底色通透、高亮字体与全量 ANSI 色彩保留 */
.terminal,
.xterm,
.xterm-viewport,
.xterm-screen,
[class*="terminal"] {
    background-color: transparent !important;
    background: transparent !important;
}

/* 11.6.1 终端默认普通文字亮度提升至 96%（避免影响彩色 span） */
.terminal .xterm-rows,
.xterm .xterm-rows {
    color: rgba(255, 255, 255, 0.96) !important;
    -webkit-font-smoothing: antialiased !important;
}

/* 仅对未指定前景色类的无色普通文字 span 进行亮白增强，严格排除所有 xterm-fg-* 与行内 color 样式 */
.terminal .xterm-rows span:not([class*="xterm-fg-"]):not([style*="color"]),
.xterm .xterm-rows span:not([class*="xterm-fg-"]):not([style*="color"]) {
    color: rgba(255, 255, 255, 0.96) !important;
    -webkit-font-smoothing: antialiased !important;
}

/* 标准白色与高亮白色字符明确保持 96% 极清亮度 */
.terminal .xterm-rows .xterm-fg-7,
.xterm .xterm-rows .xterm-fg-7,
.terminal .xterm-rows .xterm-fg-15,
.xterm .xterm-rows .xterm-fg-15 {
    color: rgba(255, 255, 255, 0.96) !important;
}

/* 11.6.2 全量 ANSI 彩色字体高亮与饱和度优化（精准保留红、绿、黄、青、蓝、紫等原有颜色，且透亮醒目） */
/* 红色系（错误、失败、删除） */
.xterm-rows .xterm-fg-1 { color: #f87171 !important; }
.xterm-rows .xterm-fg-9 { color: #fca5a5 !important; }

/* 绿色系（成功、通过、添加） */
.xterm-rows .xterm-fg-2 { color: #4ade80 !important; }
.xterm-rows .xterm-fg-10 { color: #86efac !important; }

/* 黄色系（警告、脚本路径、进行中） */
.xterm-rows .xterm-fg-3 { color: #facc15 !important; }
.xterm-rows .xterm-fg-11 { color: #fde047 !important; }

/* 蓝色系（标识符、命令、信息） */
.xterm-rows .xterm-fg-4 { color: #60a5fa !important; }
.xterm-rows .xterm-fg-12 { color: #93c5fd !important; }

/* 洋红/紫色系（特殊关键字、转义符） */
.xterm-rows .xterm-fg-5 { color: #c084fc !important; }
.xterm-rows .xterm-fg-13 { color: #e879f9 !important; }

/* 青色系（字符串、属性、分隔线） */
.xterm-rows .xterm-fg-6 { color: #38bdf8 !important; }
.xterm-rows .xterm-fg-14 { color: #67e8f9 !important; }

/* 暗淡/次要文字与注释（保持暗淡区分感，但透亮不发黑） */
.xterm-rows .xterm-fg-8,
.xterm-rows .xterm-dim {
    color: rgba(255, 255, 255, 0.65) !important;
}
```
