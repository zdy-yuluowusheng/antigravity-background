# Antigravity 右侧辅助面板（总览/审查/终端）字体提亮与终端会话黑底消除方案

## 一、需求背景与问题定位

用户在开启 Antigravity 右侧辅助栏（总览 Overview、审查 Review、终端 Terminal）时，反馈了两项关键问题：
1. **字体亮度偏暗**：右侧面板中的标题、大纲条目、审查代码以及终端内的默认字体偏暗，希望在现有基础上提升约 20 个百分点；
2. **终端会话选中项黑底缺陷**：在终端面板右侧的终端会话列表中，当前选中的 `pwsh.exe` 会话呈现出一个突兀的深黑色背景实底（原生带有 `bg-secondary` 类，色值为 `#2d2d2d`），破坏了毛玻璃壁纸的通透美感。

---

## 二、优化策略与明度参数调整

根据用户需求，在现有明度基准上整体提升约 20 个百分点，并消除所有深色背景色块：

| 区域与元素 | 调整前明度 | **调整后新明度 (+20)** | 对应 CSS 渲染规则 | 视觉特性说明 |
| :--- | :---: | :---: | :--- | :--- |
| **终端会话选中项（`pwsh.exe` 激活项）** | `#2d2d2d`（深黑底）<br>文字约 80% | **95 ~ 100%** 🌟<br>*(消除黑底)* | `rgba(255, 255, 255, 0.12)` 浮层<br>`color: #ffffff !important` | 彻底移除深黑实底，变为与主步骤条一致的高雅半透明白色微光胶囊。 |
| **终端会话未选中项** | 61%（灰暗） | **82%** | `rgba(255, 255, 255, 0.82)` | 提升 20 多个百分点，清晰易辨。 |
| **终端会话悬停状态** | 原生 `hover:bg-muted` 黑底 | 微光选显 | `rgba(255, 255, 255, 0.08)` | 悬停时柔和微光，绝不显黑底。 |
| **右侧顶栏 Tab 与功能按钮** | 65% | **85%** | `rgba(255, 255, 255, 0.85)` | 图标与文字更加锐利明亮。 |
| **总览面板（Overview/制品）** | 68% | **88%** | `rgba(255, 255, 255, 0.88)` | 大纲节点与说明清晰通透。 |
| **审查面板（Review/Diff 代码）** | 70% | **90%** | `rgba(255, 255, 255, 0.90)` | 差异对比文字明亮易读，保留红绿增删色彩。 |
| **终端输出区（xterm 控制台）** | 80% | **96%** | `rgba(255, 255, 255, 0.96)` | 消除控制台普通白色字体灰暗感，清晰醒目。 |

## 三、核心 CSS 规则实现（Section 11）

```css
/* 11.2 终端右侧终端会话列表（pwsh.exe 选中项与列表项）黑底彻底消除与微光美化 */
[data-testid*="terminal-item"],
div[class*="terminal-item"],
div[data-testid*="terminal-group"] > div,
div:has(> [data-testid*="terminal-item"]) {
    background-color: transparent !important;
    background: transparent !important;
}

/* 选中项（pwsh.exe 激活项）：强效消除原生 bg-secondary 深黑底，呈现通透高雅的半透明白色微光浮层与高亮边框 */
[data-testid*="terminal-item"].bg-secondary,
[data-testid*="terminal-item"][class*="bg-secondary"],
[data-testid*="terminal-item"][data-state="active"],
[data-testid*="terminal-item"][aria-selected="true"],
[data-testid*="terminal-item"][data-active="true"],
div[class*="terminal-item"].bg-secondary,
div[class*="terminal-item"][class*="bg-secondary"] {
    background-color: rgba(255, 255, 255, 0.12) !important;
    background: rgba(255, 255, 255, 0.12) !important;
    border: 1px solid rgba(255, 255, 255, 0.22) !important;
    border-radius: 6px !important;
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.15) !important;
}

/* 终端会话选中项内部文本与图标直接保持亮白 */
[data-testid*="terminal-item"].bg-secondary *,
[data-testid*="terminal-item"][class*="bg-secondary"] * {
    color: #ffffff !important;
}

/* 终端会话悬停状态：覆盖原生 hover:bg-muted 深黑色，统一为轻盈柔和的白色微光 */
[data-testid*="terminal-item"]:hover,
[data-testid*="terminal-item"].hover\:bg-muted:hover,
div[class*="terminal-item"]:hover {
    background-color: rgba(255, 255, 255, 0.08) !important;
    background: rgba(255, 255, 255, 0.08) !important;
    border-radius: 6px !important;
}

/* 终端未选中会话文本与图标明度拉升 20 */
[data-testid*="terminal-item"] span,
[data-testid*="terminal-item"] div,
[data-testid*="terminal-item"] svg,
[data-testid*="terminal-item"] {
    color: rgba(255, 255, 255, 0.82) !important;
    -webkit-font-smoothing: antialiased !important;
}

/* 11.4 总览面板 (Overview) 字体明度拉升至 88% ~ 100% */
[data-testid*="overview"],
[data-testid*="outline"],
[class*="overview"],
[class*="ArtifactViewer"],
[class*="ArtifactViewer"] p,
[class*="ArtifactViewer"] span,
[class*="ArtifactViewer"] li {
    color: rgba(255, 255, 255, 0.88) !important;
    -webkit-font-smoothing: antialiased !important;
}

/* 11.5 审查面板 (Review / Diff) 代码与文字明度拉升至 90% */
[data-testid*="review"],
[data-testid*="diff"],
[class*="review"],
[class*="diff"],
[data-testid*="review"] p,
[data-testid*="review"] span:not(.text-green-500):not(.text-red-500),
[data-testid*="diff"] span:not(.text-green-500):not(.text-red-500) {
    color: rgba(255, 255, 255, 0.90) !important;
    -webkit-font-smoothing: antialiased !important;
}

/* 11.6 终端面板 (Terminal) 控制台普通文字明度拉升至 96% */
.terminal .xterm-rows,
.terminal [class*="xterm-dom-renderer"],
.xterm-dom-renderer-owner-4,
[class*="terminal"] span:not([class*="ansi-green"]):not([class*="ansi-yellow"]):not([class*="ansi-red"]):not([class*="ansi-cyan"]) {
    color: rgba(255, 255, 255, 0.96) !important;
    -webkit-font-smoothing: antialiased !important;
}
```

## 四、部署与生效方式

已完成系统目录同步覆写，在 Antigravity 界面按下 **`Ctrl + R`** 即可热重载查看右侧通透微光与清晰字体效果。
