# Antigravity 流程图背景透明化与节点卡片保黑技术方案

## 一、需求背景与问题定位

在 Antigravity 客户端会话中渲染 Mermaid 流程图（或架构图/时序图）时，流程图外层呈现出大面积深灰黑色矩形色块（`#1F1F1F`），严重遮挡了底层晨雾森林毛玻璃壁纸，破坏了界面的通透美感。

### 用户明确诉求
- **流程图的大背景改成完全透明**，透出底层的壁纸与毛玻璃效果；
- **各节点的卡片保持深黑色**（深色卡片 + 白色文字与细边框），确保文字可读性与节点辨识度。

---

## 二、底层渲染逆向分析

通过对运行时 Chromium 渲染进程与 DOM 树的深度探查，定位到流程图的渲染机制如下：

1. **DOM 结构树**：
   ```html
   <pre class="...">
     <div class="mermaid-wrapper relative my-4 cursor-pointer" role="button" tabindex="0">
       <img alt="Mermaid diagram" src="data:image/svg+xml;base64,PHN2ZyB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmci...==">
     </div>
   </pre>
   ```

2. **SVG 内联变量与底色定义**：
   对 `img.src` 中的 Base64 解码后，提取出根节点定义：
   ```xml
   <svg xmlns="http://www.w3.org/2000/svg" viewBox="..." 
        style="--bg:#1F1F1F;--fg:#CCCCCC;--line:#CCCCCC;--accent:#0078D4;--muted:#CCCCCCCC;--surface:#181818;--border:#CCCCCC;background:var(--bg)">
     <style>
       svg {
         --_text: var(--fg);
         --_arrow: var(--accent, color-mix(...));
         --_node-fill: var(--surface, color-mix(in srgb, var(--fg) 3%, var(--bg)));
         --_node-stroke: var(--border, color-mix(in srgb, var(--fg) 20%, var(--bg)));
         --_group-fill: var(--bg);
       }
     </style>
     ...
   </svg>
   ```

3. **关键发现**：
   - **大背景来源**：由 SVG 根属性 `background:var(--bg)` 产生，且 `--bg:#1F1F1F;`，形成了遮挡壁纸的整块深黑色背景；
   - **节点卡片底色**：各节点矩形填充由 `--_node-fill: var(--surface, ...)` 决定，其绑定的是 `--surface:#181818;`（纯黑/深黑色）；
   - **穿透限制**：由于 SVG 是内嵌在 `<img src="data:image/svg+xml;base64,...">` 中由独立图片上下文渲染，常规宿主 CSS 无法穿透进 `<img>` 内部直接修改内联样式。

## 三、双层协同解决方案

为了实现“大背景彻底透明，节点卡片精准保黑”，采用 **“插件层动态 SVG 拦截 + CSS 层容器微光美化”** 双层协同架构：

### 1. 插件层：SVG 实时动态透明化引擎 (`汉化插件/index.js`)

在 BetterGravity 插件引擎中植入 `processMermaidImg` 与 `startMermaidTransparencyKeeper`：
- **精准正则替换**：
  1. `background:\s*var\(--bg\)` 替换为 `background:transparent`；
  2. `--bg:\s*#[0-9a-fA-F]+` 替换为 `--bg:transparent`；
  3. `--_group-fill:\s*var\(--bg\);` 替换为 `--_group-fill: transparent;`；
  4. **严格保留** `--surface:#181818` 与 `--_node-fill`，确保卡片保持沉稳深黑色；
- **重编码与标记**：
  - 将处理后的 SVG 重新打包为 Base64 并写回 `img.src`；
  - 标记 `data-mermaid-transparent="true"`，防止重复执行或陷入重绘死循环；
- **全生命周期保活监听**：
  - 首屏启动时立即扫描当前 DOM；
  - 挂载 `MutationObserver` 监听 DOM 树新增节点与 `src` 属性变化，即使在会话虚拟列表滚动、切换历史对话、或者点击全屏弹窗时，均能实现微秒级实时透明化。

### 2. CSS 层：第 18 节流程图专用微光样式 (`晨雾森林毛玻璃主题.css`)

在主题样式表中新增流程图专属规则：
- **外层容器与包裹块纯透明**：
  - `.mermaid-wrapper`、`pre:has(.mermaid-wrapper)`、`div:has(> .mermaid-wrapper)` 设为 `background: transparent !important` 与 `box-shadow: none !important`；
- **精致微光圆角外框**：
  - 给 `pre:has(.mermaid-wrapper)` 增加 `border: 1px solid rgba(255, 255, 255, 0.12) !important`，悬停时微光高亮 `rgba(255, 255, 255, 0.25)`；
- **全屏模态框毛玻璃化**：
  - 当点击流程图弹出 Lightbox 预览时，模态底色由原生纯黑转为高质感磨砂毛玻璃：`rgba(18, 22, 26, 0.75)` + `backdrop-filter: blur(24px)`。

## 四、核心实现代码

### 1. 插件层核心逻辑 (`汉化插件/index.js`)
```javascript
function processMermaidImg(img) {
  if (!img) return false;
  const src = img.getAttribute('src') || '';
  if (!src.startsWith('data:image/svg+xml;base64,')) return false;

  if (img.dataset.mermaidTransparent === 'true' && !src.includes('background:var(--bg)') && !src.includes('--bg:#')) {
    return false;
  }

  try {
    const rawBase64 = src.slice('data:image/svg+xml;base64,'.length);
    let svgText = Buffer.from(rawBase64, 'base64').toString('utf8');

    let modified = false;
    if (svgText.includes('background:var(--bg)')) {
      svgText = svgText.replace(/background:\s*var\(--bg\)/g, 'background:transparent');
      modified = true;
    }
    if (/--bg:\s*#[0-9a-fA-F]+/i.test(svgText)) {
      svgText = svgText.replace(/--bg:\s*#[0-9a-fA-F]+/gi, '--bg:transparent');
      modified = true;
    }
    if (svgText.includes('--_group-fill:    var(--bg);')) {
      svgText = svgText.replace('--_group-fill:    var(--bg);', '--_group-fill: transparent;');
      modified = true;
    }

    if (modified) {
      const newBase64 = Buffer.from(svgText, 'utf8').toString('base64');
      img.setAttribute('src', 'data:image/svg+xml;base64,' + newBase64);
      img.dataset.mermaidTransparent = 'true';
      return true;
    }
  } catch (err) {
    // 容错处理
  }
  return false;
}
```

### 2. CSS 层样式规则 (`主题样式/晨雾森林毛玻璃主题.css`)
```css
/* ================= 18. 流程图（Mermaid / 架构与时序图）：背景纯透明、节点卡片保持黑色 ================= */
.mermaid-wrapper,
pre:has(.mermaid-wrapper),
pre:has(img[alt*="Mermaid"]),
div:has(> .mermaid-wrapper) {
    background-color: transparent !important;
    background: transparent !important;
    backdrop-filter: none !important;
    -webkit-backdrop-filter: none !important;
    box-shadow: none !important;
}

pre:has(.mermaid-wrapper),
pre:has(img[alt*="Mermaid"]) {
    border: 1px solid rgba(255, 255, 255, 0.12) !important;
    border-radius: 12px !important;
    padding: 12px 16px !important;
    transition: border-color 0.2s ease, box-shadow 0.2s ease !important;
}

pre:has(.mermaid-wrapper):hover,
pre:has(img[alt*="Mermaid"]):hover {
    border-color: rgba(255, 255, 255, 0.25) !important;
    box-shadow: 0 4px 20px rgba(0, 0, 0, 0.25) !important;
}
```

## 五、验证与生效方法

1. **工程同步**：
   运行 PowerShell 一键同步脚本：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\核心脚本\一键同步到系统.ps1
   ```
2. **热重载生效**：
   在 Antigravity 客户端窗口中按下 <kbd>Ctrl</kbd> + <kbd>R</kbd>，流程图大背景即刻变为纯透明，透显出晨雾森林壁纸，且内部每个节点卡片均完美保持深黑色！
