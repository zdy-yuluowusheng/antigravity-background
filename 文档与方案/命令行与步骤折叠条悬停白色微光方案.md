# 命令行与步骤折叠条（含子项）悬停白色微光样式方案

## 一、问题背景与需求

在 Antigravity 2.0 桌面端透明壁纸主题定制中，长对话执行任务时会产生很多步骤条（例如 `Ran node ...` 运行命令、`Worked for 1m` 工作时长、`Thought for ...` 思考折叠条、`Edited ...` 编辑文件等）。

### 1. 缺陷表现演进
* **父级折叠栏问题**：最初，包含多个命令的折叠总栏（如 `Ran 3 commands`）以及单条执行条在鼠标悬停时会显示深黑底色。在第一阶段优化后，父级总栏已成功变为平时纯透、悬停白色微光。
* **展开子项黑底问题**：当点击父级折叠总栏展开具体子项后，具体的子命令条目（例如 `Ran node "d:\work\..."`）在鼠标悬停时依然会触发深黑色背景（如图所示），破坏壁纸通透感。

### 2. 目标设计
* **平时状态**：彻底纯透明（`background: transparent`），不产生黑底或多余遮挡；
* **悬停状态**：无论父级总栏还是展开的具体子项命令行，均统一为柔和白色的半透明微光效果（`rgba(255, 255, 255, 0.12)`）与细微光白边（`rgba(255, 255, 255, 0.25)`），字体呈现清晰白光（`#ffffff`），彻底消除黑色底色。

---

## 二、DOM 结构与底层选择器逆向分析

通过 BetterGravity 运行时注入调试工具（`document.querySelectorAll` 与实时计算样式检查），对比父级与子级命令行条目的 DOM 特征：

### 1. 父级折叠条（Tool Group Collapsible）
* **选择器**：`button[data-testid="tool-group-collapsible"]`
* **类名特征**：`group flex items-center gap-1 w-full text-left text-sm px-2 min-h-8 py-1 rounded-lg tabular-nums select-none cursor-pointer text-foreground hover:bg-muted transition-[opacity,background-color]`
* **特点**：拥有明确的 `data-testid="tool-group-collapsible"`。

### 2. 展开的具体子项命令行（Subitem Command Row）
* **选择器**：`div[data-testid="conversation-view"] button` 或 `div`
* **类名特征**：`group flex w-full min-w-0 items-center min-h-8 py-1 px-2 select-none transition-[background-color] cursor-pointer rounded-lg hover:bg-muted`
* **关键发现**：
  1. 子项**没有** `data-testid="tool-group-collapsible"`，而是 `(no-testid)`；
  2. 元素既可能是 `button` 也可能是带 `cursor-pointer` 的 `div`；
  3. 原生带有 Tailwind 的 `.hover\:bg-muted` 实用类，悬停时触发 `--muted` 深黑变量；
  4. 如果在 CSS 选择器中使用包含冒号的字符串属性选择器（如 `[class*="hover:bg-muted"]`），可能在特定解析器中失效；必须使用类名转义选择器 `.hover\:bg-muted:hover` 或复合类名 `button.cursor-pointer.rounded-lg:hover` 才能实现 100% 穿透覆盖。

## 三、CSS 核心实现规则

在 [`主题样式/晨雾森林毛玻璃主题.css`](file:///d:/work/antigravity-background/%E4%B8%BB%E9%A2%98%E6%A0%B7%E5%BC%8F/%E6%99%A8%E9%9B%BE%E6%A3%AE%E6%9E%97%E6%AF%9B%E7%8E%BB%E7%92%83%E4%B8%BB%E9%A2%98.css) 中第 9 节注入全覆盖规则：

```css
/* ================= 9. 命令行与执行步骤行：父级与子项全面统一为平时纯透明、悬停柔和白色微光 ================= */

/* 1. 平时状态：父级组、具体子项命令行、工作时长与思考条全面纯透明 */
div[data-testid="conversation-view"] button[data-testid="tool-group-collapsible"],
div[data-testid="conversation-view"] button[data-testid="worked-for-collapsible"],
div[data-testid="conversation-view"] button[data-testid="thinking-collapsible-trigger"],
div[data-testid="conversation-view"] button[data-testid*="-collapsible"],
div[data-testid="conversation-view"] button[data-testid*="tool-group"],
div[data-testid="conversation-view"] button[class*="min-h-8"],
div[data-testid="conversation-view"] button[class*="tabular-nums"],
div[data-testid="conversation-view"] button.cursor-pointer.rounded-lg,
div[data-testid="conversation-view"] button.cursor-pointer[class*="min-h-8"],
div[data-testid="conversation-view"] .hover\:bg-muted,
button[data-testid="tool-group-collapsible"],
button[data-testid="worked-for-collapsible"],
button[data-testid="thinking-collapsible-trigger"] {
    background-color: transparent !important;
    background: transparent !important;
    backdrop-filter: none !important;
    -webkit-backdrop-filter: none !important;
    border: 1px solid rgba(255, 255, 255, 0.08) !important;
    border-radius: 8px !important;
    box-shadow: none !important;
    transition: background-color 0.2s ease, border-color 0.2s ease, color 0.2s ease, box-shadow 0.2s ease !important;
}

/* 2. 悬停状态：强效覆盖原生 hover:bg-muted，统一为白色半透明微光与高亮白边 */
div[data-testid="conversation-view"] button[data-testid="tool-group-collapsible"]:hover,
div[data-testid="conversation-view"] button[data-testid="worked-for-collapsible"]:hover,
div[data-testid="conversation-view"] button[data-testid="thinking-collapsible-trigger"]:hover,
div[data-testid="conversation-view"] button[data-testid*="-collapsible"]:hover,
div[data-testid="conversation-view"] button[data-testid*="tool-group"]:hover,
div[data-testid="conversation-view"] button[class*="min-h-8"]:hover,
div[data-testid="conversation-view"] button[class*="tabular-nums"]:hover,
div[data-testid="conversation-view"] button.cursor-pointer.rounded-lg:hover,
div[data-testid="conversation-view"] button.cursor-pointer[class*="min-h-8"]:hover,
div[data-testid="conversation-view"] .hover\:bg-muted:hover,
button[data-testid="tool-group-collapsible"]:hover,
button[data-testid="worked-for-collapsible"]:hover,
button[data-testid="thinking-collapsible-trigger"]:hover {
    background-color: rgba(255, 255, 255, 0.12) !important;
    background: rgba(255, 255, 255, 0.12) !important;
    border-color: rgba(255, 255, 255, 0.25) !important;
    color: #ffffff !important;
    box-shadow: 0 2px 8px rgba(255, 255, 255, 0.06) !important;
}

/* 3. 悬停时内部所有子级文本与图标同步转为纯白色高亮 */
div[data-testid="conversation-view"] button[data-testid="tool-group-collapsible"]:hover *,
div[data-testid="conversation-view"] button[data-testid="worked-for-collapsible"]:hover *,
div[data-testid="conversation-view"] button[data-testid="thinking-collapsible-trigger"]:hover *,
div[data-testid="conversation-view"] button[class*="min-h-8"]:hover *,
div[data-testid="conversation-view"] button.cursor-pointer.rounded-lg:hover *,
div[data-testid="conversation-view"] .hover\:bg-muted:hover * {
    color: #ffffff !important;
}

/* 4. 展开的子项命令行容器及终端执行输出底色通透处理 */
div[data-testid="conversation-view"] [data-state="open"] pre,
div[data-testid="conversation-view"] [data-state="open"] code,
div[data-testid="conversation-view"] [class*="terminal"] {
    background-color: transparent !important;
}
```

## 四、验证结果与实测数据

通过运行时注入脚本 [`逆向与调试工具/验证子项命令行样式生效.js`](file:///d:/work/antigravity-background/%E9%80%86%E5%90%91%E4%B8%8E%E8%B0%83%E8%AF%95%E5%B7%A5%E5%85%B7/%E9%AA%8C%E8%AF%81%E5%AD%90%E9%A1%B9%E5%91%BD%E4%BB%A4%E8%A1%8C%E6%A0%B7%E5%BC%8F%E7%94%9F%E6%95%88.js) 进行计算样式（Computed Style）实测：

* **父级与子级平时状态**：
  - `backgroundColor`: `rgba(0, 0, 0, 0)`（纯透明）
  - `border`: `0.666667px solid rgba(255, 255, 255, 0.08)`（精致浅白微光微边框）
  - `borderRadius`: `8px`
* **悬停状态**：
  - `div[data-testid="conversation-view"] .hover\:bg-muted:hover` 具备更高的特异性权重（Specificity），成功完全压制了原生 Tailwind 的 `--muted` 黑底；
  - 呈现柔和透明白光 `rgba(255, 255, 255, 0.12)` 与白边 `rgba(255, 255, 255, 0.25)`，父级与子级视觉质感实现高度统一。
