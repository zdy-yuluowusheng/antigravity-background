# 对话提问防重叠与毛玻璃雾化矩形框技术方案

本文档详细记录了在 **对话「提问与回答文字重叠问题排查」** 中，针对 Antigravity 2.0 聊天消息流在拉动滚动条时发生文字重叠的缺陷成因、DOM 逆向分析、样式方案设计与生效验证。

---

## 一、问题背景与现象

在应用了透明毛玻璃主题后，当用户向智能体发出提问并获取到较长的回答时，在聊天画板中**向下滚动查看回答内容**时出现了严重的视觉重合现象：

1. **吸顶粘滞重叠**：
   * 原生 Antigravity 会将当前轮次的用户提问卡片固定吸顶在聊天区域上方（`sticky top-0`）。
   * 随着用户拉动滚动条查看下方的长文本，底部的回答文字、“Worked for 2m” 状态条等内容向上滚动，穿过吸顶区域。
2. **纯透明导致的重叠乱码**：
   * 由于主题工程此前为了追求通透感，对全局容器及卡片执行了全局穿透（`--background: 0 0% 0% / 0` 及 `--card: 0 0% 0% / 0`），导致吸顶的用户提问区域背景完全变为 100% 纯透明。
   * 下方向上滚动的回答文字与吸顶的用户提问文字直接在同一物理位置叠合，形成字叠字、杂乱不可辨识的视觉缺陷。
3. **用户改进诉求**：
   * 对话问题区域需要与底部对话框（输入框）保持一致，呈现为一个带有**毛玻璃高斯模糊雾化、精致边框与深色半透明底色**的独立矩形框，在吸顶时将下方向上穿行的回答文字优雅地阻隔并高斯虚化在底层，确保用户提问文字始终清晰可见。

---

## 二、DOM 结构逆向与缺陷成因排查

通过 BetterGravity 插件运行时注入 DOM 探查钩子，精准抓取了当前对话消息树的实际层级与盒模型：

### 1. 吸顶容器结构链路
```html
<div role="article" aria-label="User message" class="sticky top-0 z-10 mb-4">
  <div class="relative bg-background md-sticky-message-bleed after:content-[''] after:absolute after:left-0 after:right-0 after:top-full after:h-7 after:bg-gradient-to-b after:from-background after:to-transparent after:pointer-events-none">
    <div class="flex w-full flex-row">
      <div class="flex min-w-0 grow flex-col">
        <div data-testid="user-input-step" class="flex flex-col w-full gap-2 group/user-input-step pt-4">
          <div class="w-full">
            <div data-testid="lifted-context-menu-trigger" class="relative p-px rounded-xl bg-card-border">
              <div class="relative flex flex-row items-end gap-2 p-1.5 rounded-[calc(theme(borderRadius.xl)-1px)] bg-card overflow-hidden">
                <div class="flex-1 p-0.5 max-h-[10vh] overflow-hidden cursor-pointer" style="mask-image: ...">
                  <!-- 用户提问正文内容与图片附件 -->
                </div>
              </div>
            </div>
          </div>
        </div>
      </div>
    </div>
  </div>
</div>
```

### 2. 缺陷根本原因
* 原生 Antigravity 在 `.md-sticky-message-bleed` 上应用了纯黑死色的 `bg-background`，并在底部用伪元素 `after:bg-gradient-to-b after:from-background after:to-transparent` 制作了一个 28px 的黑色渐变过渡带，以此挡住向上滚动的文字。
* 在我们的毛玻璃主题中，全局将 `.bg-background` 和 `--card` 强行设为 `transparent !important`，导致官方原本的黑色实底遮罩和渐变完全失效，整个提问吸顶条变成了空心透明。

## 三、毛玻璃雾化矩形框设计方案

为与底部对话框（输入框）的精致设计语言保持完美一致，并兼顾壁纸的高级通透感与遮盖文字的实用性，制定了如下 CSS 穿透方案：

#### 1. 核心 CSS 规则实现
```css
/* ================= 7. 用户提问卡片与吸顶：纯透明高透毛玻璃雾化矩形框 (1:1对齐底部输入框) ================= */
/*
 * 解决滚动时下方长回答文字向上穿透的重叠问题
 * 保持背景完全透明（彻底去除黑色与死色），仅使用纯粹的高斯模糊雾化与精致边框与底部输入框对齐
 */
[data-testid="user-input-step"] [data-testid="lifted-context-menu-trigger"],
[data-testid="user-input-step"] .bg-card-border,
[data-testid="user-input-step"] [class*="bg-card-border"],
div[role="article"].sticky [data-testid="lifted-context-menu-trigger"],
div[role="article"].sticky .bg-card-border,
.md-sticky-message-bleed [data-testid="lifted-context-menu-trigger"],
.md-sticky-message-bleed .bg-card-border {
    background-color: transparent !important;
    background: transparent !important;
    backdrop-filter: blur(16px) saturate(120%) !important;
    -webkit-backdrop-filter: blur(16px) saturate(120%) !important;
    border: 1px solid rgba(255, 255, 255, 0.16) !important;
    border-radius: 16px !important;
    box-shadow: 0 8px 32px rgba(0, 0, 0, 0.20) !important;
}

/* 用户提问内层容器保持纯净透明，避免多层色块或灰底冲突 */
[data-testid="user-input-step"] .bg-card,
[data-testid="user-input-step"] [class*="bg-card"],
div[role="article"].sticky .bg-card {
    background-color: transparent !important;
    background: transparent !important;
    box-shadow: none !important;
}

/* 吸顶容器自身透明化，避免产生大面积纯黑背景遮挡壁纸 */
div[role="article"].sticky,
.sticky.top-0,
.md-sticky-message-bleed {
    background-color: transparent !important;
    background: transparent !important;
}

/* 移除原生黑色实底渐变伪元素，避免边缘生硬裁切 */
.md-sticky-message-bleed::after {
    display: none !important;
    content: none !important;
}
```

### 2. 设计要点与技术细节
1. **背景彻底纯透明 (`background-color: transparent !important;`)**：
   * 坚决剔除任何黑色/深色底色，彻底杜绝出现死黑大色块遮盖壁纸的问题，保持整个主界面的纯粹通透与森林意境。
2. **纯粹的高斯模糊雾化 (`blur(16px) saturate(120%)`)**：
   * 采用无底色的纯光学高斯模糊滤镜，背后的壁纸透过矩形框时呈现自然柔和的磨砂雾化效果。
   * 下方向上滚动的长文本回答在穿过矩形框背后时，文字被 16px 高斯模糊深度虚化为雾状微光，从而消除与正面上提问文字的重叠干扰。
3. **微光细边框 (`border: 1px solid rgba(255, 255, 255, 0.16)`) 与圆角 (`16px`)**：
   * 与图二底部输入框（`[data-testid="agent-input-box"] .bg-card-border`）的几何外形、圆角半径与边框质感 1:1 精确对齐。
4. **轻微立体投影 (`box-shadow: 0 8px 32px rgba(0, 0, 0, 0.20)`)**：
   * 建立微弱的悬浮空间层次，与底部输入框投影参数保持一致。

## 四、生效验证与计算样式检测

通过注入探查脚本对当前客户端渲染树进行实际抓取，计算样式（`getComputedStyle`）最新验证结果如下：

```json
{
  "found": true,
  "bg": "rgba(0, 0, 0, 0)",
  "backdrop": "blur(16px) saturate(1.2)",
  "border": "0.666667px solid rgba(255, 255, 255, 0.16)",
  "borderRadius": "16px",
  "boxShadow": "rgba(0, 0, 0, 0.2) 0px 8px 32px 0px"
}
```

* **验证结论**：`bg` 确认为完全透明的 `rgba(0, 0, 0, 0)`，黑色底色已被彻底清除；`backdrop` 为纯粹的高透毛玻璃雾化，矩形框样式与底部输入框（图二）1:1 完美契合。
