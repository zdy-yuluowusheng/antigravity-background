# 代码块、引用链接与变更条透明雾化技术方案

本文档记录了在 **对话「代码块与引用链接样式调整」** 中，针对 Antigravity 2.0 聊天消息流中的代码块、文件引用胶囊（Mention Chips）、行内代码以及文件变更状态条的 DOM 逆向分析、样式方案设计与生效验证。

---

## 一、问题背景与现象

在透明毛玻璃主题下，界面的主体背景与用户提问卡片已实现通透雾化。但在对话正文中，仍有若干内部组件带有原生的纯黑色遮罩底色（如用户反馈截图所示）：

1. **代码块容器整体发黑**：
   * 代码块（Code Block）卡片外层带有深黑色实底（`color(srgb 0.0861764 0.0861764 0.0861764)`），大面积遮挡底层的森林壁纸。
2. **文件引用链接胶囊（Mention Chips）发黑**：
   * 正文中的文件引用胶囊（如 `{} 主题样式/晨雾森林毛玻璃主题.css`）呈现为一个黑色无通透感的死色药丸框。
3. **文件变更状态条与折叠栏发黑**：
   * 类似 `3 files changed +46 -43 >` 的折叠条及右侧的 `审查` 按钮带有深色背景，破坏了毛玻璃主题的通透整体感。

---

## 二、DOM 结构逆向与关键选择器定位

通过 BetterGravity 运行时探查，获取到了这三类组件的真实 DOM 结构与类名链路：

### 1. 代码块结构
```html
<div class="relative whitespace-pre-wrap word-break-all my-2 rounded-xl bg-muted border">
  <div class="min-h-7 relative box-border flex flex-row items-center justify-between rounded-t border-b border-border px-2 py-0.5">
    <!-- 语言标识与右上角复制/操作按钮 -->
    <span>css</span>
  </div>
  <div class="p-3">
    <div class="code-block w-full text-xs cursor-text">
      <pre><code>...代码高亮正文...</code></pre>
    </div>
  </div>
</div>
```

### 2. 引用链接胶囊结构
```html
<span class="context-scope-mention">
  <button class="select-none inline-flex items-baseline align-baseline text-sm font-medium inline-pill gap-0.5 rounded-md p-0.5 text-foreground cursor-pointer hover:bg-secondary">
    <svg>...</svg>
    <span>主题样式/晨雾森林毛玻璃主题.css</span>
  </button>
</span>
```

### 3. 文件变更状态条结构
```html
<div class="flex flex-wrap items-center justify-between pl-3 p-2 border text-sm files-changed-header gap-1 rounded-xl cursor-pointer hover:bg-muted">
  <div>3 files changed +46 -43 ></div>
  <button class="review-button shrink-0 flex items-center gap-1 px-1.5 py-0.5 rounded-md text-sm border bg-muted">审查</button>
</div>
```

> [!IMPORTANT]
> **避坑发现**：
> Antigravity 2.0 对话渲染区域的外层容器为 `<div data-testid="conversation-view">`，**整个页面中根本不存在 `<main>` 语义标签**！因此先前使用 `main ...` 作为前缀的规则均会静默失效。本次调整彻底去除了 `main` 前缀限制，改用更具穿透力的通用选择器。

## 三、纯透明通透方案实现（移除雾化处理）

由于代码块使用高斯模糊雾化（`backdrop-filter: blur`）会导致壁纸的局部高清树木细节被涂抹为光斑，经实际视觉检验与用户反馈，确定将代码块、引用链接与状态条彻底调整为**纯透明（移除模糊滤镜，仅保留微光细边框）**，使壁纸原貌得以完整透现。

在 [`主题样式/晨雾森林毛玻璃主题.css`](file:///d:/work/antigravity-background/%E4%B8%BB%E9%A2%98%E6%A0%B7%E5%BC%8F/%E6%99%A8%E9%9B%BE%E6%A3%AE%E6%9E%97%E6%AF%9B%E7%8E%BB%E7%92%83%E4%B8%BB%E9%A2%98.css) 中更新第 8 节专属规则：

```css
/* ================= 8. 代码块、行内代码与引用链接胶囊：纯透明极致通透 (移除雾化) ================= */
/* 8.1 代码块外层整体卡片：纯透明无底色、移除高斯模糊雾化，直显高清壁纸 */
pre,
.code-block,
div[class*="word-break-all"][class*="rounded-xl"],
div[class*="whitespace-pre-wrap"][class*="rounded-xl"],
div[class*="whitespace-pre-wrap"][class*="bg-muted"],
div:has(> div > .code-block),
div:has(> .code-block) {
    background-color: transparent !important;
    background: transparent !important;
    backdrop-filter: none !important;
    -webkit-backdrop-filter: none !important;
    border: 1px solid rgba(255, 255, 255, 0.12) !important;
    border-radius: 12px !important;
    box-shadow: none !important;
}

/* 代码块内部代码渲染区纯透明 */
pre code,
.code-block,
.code-block pre,
.code-block code,
[class*="syntax-highlighter"] {
    background-color: transparent !important;
    background: transparent !important;
    border: none !important;
    box-shadow: none !important;
}

/* 代码块顶部语言标题栏 (如 css、js 等标识与右侧复制按钮) */
div[class*="whitespace-pre-wrap"] > div[class*="border-b"],
div[class*="whitespace-pre-wrap"] div[class*="rounded-t"],
div[class*="border-border"][class*="rounded-t"] {
    background-color: transparent !important;
    background: transparent !important;
    border-bottom: 1px solid rgba(255, 255, 255, 0.08) !important;
    backdrop-filter: none !important;
    -webkit-backdrop-filter: none !important;
}

/* 8.2 行内代码与引用链接胶囊 (如 {} 主题样式/晨雾森林毛玻璃主题.css) */
code:not(pre code),
.inline-pill,
[class*="inline-pill"],
.context-scope-mention,
.context-scope-mention button,
span[class*="context-scope-mention"] button,
button:has(svg):has(span),
a[href*="file://"],
[class*="chip"] {
    background-color: transparent !important;
    background: transparent !important;
    backdrop-filter: none !important;
    -webkit-backdrop-filter: none !important;
    border: 1px solid rgba(255, 255, 255, 0.14) !important;
    border-radius: 6px !important;
    transition: background-color 0.2s ease, border-color 0.2s ease !important;
}

/* 引用链接胶囊鼠标悬停微光反馈 */
code:not(pre code):hover,
[class*="inline-pill"]:hover,
.inline-pill:hover,
.context-scope-mention button:hover,
span[class*="context-scope-mention"] button:hover,
a[href*="file://"]:hover,
[class*="chip"]:hover {
    background-color: rgba(255, 255, 255, 0.10) !important;
    border-color: rgba(255, 255, 255, 0.22) !important;
}

/* 8.3 文件变更状态条与折叠栏 (如 3 files changed +46 -43 > 与 审查 按钮) */
.files-changed-header,
div[class*="files-changed-header"],
div[class*="files-changed"] {
    background-color: transparent !important;
    background: transparent !important;
    backdrop-filter: none !important;
    -webkit-backdrop-filter: none !important;
    border: 1px solid rgba(255, 255, 255, 0.12) !important;
    border-radius: 12px !important;
    box-shadow: none !important;
    transition: background-color 0.2s ease !important;
}

.files-changed-header:hover,
div[class*="files-changed-header"]:hover {
    background-color: rgba(255, 255, 255, 0.06) !important;
}

/* 状态条右侧的【审查】操作按钮 */
.review-button,
button[class*="review-button"] {
    background-color: transparent !important;
    background: transparent !important;
    backdrop-filter: none !important;
    -webkit-backdrop-filter: none !important;
    border: 1px solid rgba(255, 255, 255, 0.14) !important;
    border-radius: 6px !important;
    transition: background-color 0.2s ease !important;
}

.review-button:hover,
button[class*="review-button"]:hover {
    background-color: rgba(255, 255, 255, 0.15) !important;
}
```

## 四、计算样式与生效验证

通过对运行时页面元素进行抓取，三类组件的最新实时计算样式（`getComputedStyle`）验证结果如下：

```json

    "borderRadius": "12px"
  },
  "fileChip": {
    "found": true,
    "bg": "rgba(0, 0, 0, 0)",
    "backdrop": "none",
    "border": "0.666667px solid rgba(255, 255, 255, 0.14)",
```

* **代码块**：完全消除死黑色底色与高斯模糊涂抹感，呈现纯透明悬浮卡片，代码高亮直接自然悬浮在晨雾森林壁纸之上。
* **文件引用胶囊**：呈现纯透明微光细框玻璃药丸，微光通透，鼠标悬停时轻微增亮反馈。
* **文件变更条**：通透圆角长条，背景彻底纯透明，完全展现壁纸细节。
